# Yours Legal Basement — Premium One-Page Redesign

A premium single-page redesign based on the real information from the existing YLB website and the motion language of the provided Bildora reference.

## Included
- Cinematic hero using the provided YLB logo
- Lenis smooth scrolling
- GSAP + ScrollTrigger reveals and parallax
- Animated image fan
- Real pricing: from CAD 59.99/sqft
- Real package inclusions and full warranty messaging
- Professional & Affordable / Why YLB section
- Pinned horizontal project gallery on desktop
- Estimate form UI
- GTA service-area map
- Real opening hours and phone number
- Fully responsive mobile navigation and layout

## Run locally
Open `index.html` directly, or use any static server.

Example:
```bash
python -m http.server 8080
```
Then open http://localhost:8080

## Production note
The estimate form currently provides an on-page confirmation because the existing source did not provide a verified form endpoint or business email. Connect the form to your preferred backend/email provider before production launch.
